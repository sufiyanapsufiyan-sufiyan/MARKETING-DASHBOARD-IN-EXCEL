# Investment Portfolio & Market Performance Dashboard

## Project Overview

This project is an **Investment Portfolio & Market Performance Dashboard** designed to provide a clear visual overview of portfolio performance, asset allocation, market trends, and investment analysis.

The dashboard includes:
- Total Return
- Investment Portfolio Summary
- Market Performance
- Portfolio Allocation
- Asset Class Distribution
- Investment Risk Analysis
- Count of Asset Classes
- Interactive charts and visualizations
